# Travel O Friend  
**Version 3.0.0**

A **modern and responsive website** built with **Next.js**, designed for **simplicity, readability, and user-friendly navigation**.  
The project uses a clean **blue-and-white color palette** with professional typography for a modern look.

---

## ✨ Features
- ⚡ **Next.js Framework** – fast, SEO-friendly, and optimized for performance.  
- 🎨 **Modern UI/UX** – fully responsive across all devices.  
- ✍️ **Typography** –  
  - **Poppins** → headings and titles (modern, elegant style).  
  - **Roboto** → body text and descriptions (clean and easy to read).  
- 🌈 **Color Palette** –  
  - **Blue** → primary color for highlights and actions.  
  - **White** → background for clarity and focus.  

---

## 🚀 Tech Stack
- **Frontend**: Next.js (React-based framework)  
- **Package Manager**: npm  
- **Styling**: Tailwind CSS
